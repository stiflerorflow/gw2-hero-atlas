# Fast-access duo250 · route research and limits

Reviewed18October2026. This is a curated low-navigation itinerary, not a field-timed or mathematically proven global optimum. Both players reported Raptor Canyon Jumping, Springer, Skimmer, Glider Basics and Updraft Use. High Vault is not assumed.

## Objective and route selection

Choose25fresh expansion challenges, worth250HP per character, from all69HoT/PoF challenges. Minimize cold-map entry, waypoint scouting, forced waits, vertical recovery and backtracking. Fight difficulty is allowed: nearby group fights can beat distant communes. No map-completion rewards, hearts, mastery insights or repeat challenge rewards count toward the goal.

Default region blocks: Crystal Oasis4 → Desert Highlands4 → Elon Riverlands8 → Verdant Brink7 → Auric Basin2. The jungle-first option reverses the two region blocks while keeping each map’s local order. Exactly one cross-region transfer is planned.

## All-map review

- **Verdant Brink**: Seven lower-access branches selected. Canopy timing, vine walks and narrow poison-side landings are omitted.
- **Auric Basin**: Only the two arrival-area challenges selected. City/meta gates, quarry access and long cross-map branches lose on travel for this run.
- **Tangled Depths**: No default stops: tunnels, multiple vertical layers and scouting the hubs add too much navigation for characters without waypoints.
- **Dragon's Stand**: No default stops: reaching the map and its lane/meta gates is disproportionate for the first 250.
- **Crystal Oasis**: Four stops form the first desert leg. The pyramid’s interior ledges are a reserve, not a speed pick.
- **Desert Highlands**: Four eastern/central stops. The distant western forge, northern cave and tower climb remain optional replacements.
- **Elon Riverlands**: Eight stops fit the surface/skimmer circuit. Ground veterans are retained even when the fight is less trivial.
- **The Desolation**: No default stops: sulfur terrain, a cold map crossing and uncertain low-mastery shelf approaches make it a poor first-250 detour.
- **Domain of Vabbi**: No default stops: short local fights do not repay crossing the preceding map and this map from scratch.

## Cold waypoints and map links

A waypoint chat link locates a pin; it never unlocks travel. Arrival gates explicitly confirm that both characters reached the first waypoint. Later checkpoint gates confirm scouting before offering a return teleport. Contested waypoints are not treated as usable: the recorded map-entry waypoint is offered as a fallback when known on both characters. From there, use upper/surface paths back to the hub. The guide explicitly avoids treating a glider descent as a reversible climb, and does not ask players to wait for an outpost event. Individual imported waypoint availability is never inferred from the account API.

The dependency graph is Crystal Oasis→Desert Highlands, Crystal Oasis→Elon Riverlands, and Verdant Brink→Auric Basin. A parent arrival gate still appears when its challenges were skipped as prior completions. Unknown Temple of Kormir / Treacherous Path returns display road recovery instructions; a prior completed challenge does not prove its waypoint was scouted.

Desert Highlands returns through Crystal Oasis before the southeast connection to Elon Riverlands. Auric Basin uses the ordinary southwest Verdant Brink exit. HoT access requires the introductory account unlock; fresh characters still travel to its entrance. Initial desert access is established through the opening story or an eligible owned/party travel method. Neither a lounge pass nor Teleport to Friend is assumed owned.

Position maps use the existing embedded official API terrain and coordinates with only the current hero challenge and recovery waypoint. There is no fabricated straight-line terrain route or live GPS position. Vertical layers can overlap; written approaches and source movement videos resolve those cases.

## Reserve policy

- Suspicious Orichalcum: Best first jungle substitute: an uncomplicated approach, although the northward ride is extra.
- Veteran Jubua the Wildfire: Easy-access veteran once there, but the long westward ride is why it is not a default pick.
- Glowing Campfire: A reserve with additional ledge-finding north of the kraal; slower navigation than the default northern veteran.
- Branded Crystal: A reserve tower climb, deliberately excluded from the quick-access core.
- Egg Clutch (Auric Basin): A ground-access champion, but it adds a long southeast crossing from this run’s finish.
- Branded Pyramid: Last resort: interior ledges are substantially slower than the four default oasis stops.

Six reserves are appended only as needed for individual prior completions or skips. Previously recorded actual hero completions yield zero new HP. Different players can need different additional challenges. If the31-point pool cannot supply250fresh HP for each, report the deficit and allow revisiting skips / opening the full atlas; never invent a reward or assume an unverified shortcut.

## Timer and planning estimate

**150active minutes (2h30m)** is an editorial first-run planning budget, not a measured completion claim: Crystal Oasis20, Desert Highlands25, Elon Riverlands35, Verdant Brink40, Auric Basin10, cross-region transfer20. These allowances include local scouting, wayfinding, fights and ordinary map loading. Initial story/access setup before the first arrival checkpoint is excluded. Advanced waypoint/portal access can shorten the run; difficult fights, getting lost, storage problems and reserve detours can lengthen it. There is no asserted speedrun benchmark or confidence interval.

The target is editable. It does not automatically move when a replacement is added, so elapsed time remains comparable to the chosen target. Timer starts at the first arrival acknowledgment, supports pause/resume and manual start, survives reload/closed tabs using a persisted running timestamp, and automatically stops when BOTH characters have250new HP. Pause for breaks and introductory story detours. Backups export a frozen elapsed value; imported backups pause timing and require renewed run-specific map disclosure. No second-by-second localStorage write is needed.

## Progress and preservation

Run counters track only HP explicitly awarded on this run. Positive awards also update that character’s existing atlas status, keeping actual challenge completion consistent. Existing target, credits, notes and other characters are retained. Prior-completion markers in the run do not subtract older atlas credit. Undo restores only the latest award’s prior status; starting another run keeps actual earned challenges and clears only run-specific counters/checkpoints/timing. A removed tracked character pauses the run rather than reallocating their rewards.
