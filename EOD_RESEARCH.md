## Evidence and decisions

- Coverage and challenge types: [Cantha challenge list](https://wiki.guildwars2.com/wiki/List_of_hero_challenges_in_Cantha), checked against each map’s list and individual challenge pages linked in the application data.
- Coordinates, map rectangles and waypoint chat links: ArenaNet’s continent-floor API for maps [1442](https://api.guildwars2.com/v2/continents/1/floors/1/regions/37/maps/1442), [1438](https://api.guildwars2.com/v2/continents/1/floors/1/regions/37/maps/1438), [1452](https://api.guildwars2.com/v2/continents/1/floors/1/regions/37/maps/1452), [1428](https://api.guildwars2.com/v2/continents/1/floors/1/regions/37/maps/1428), and [1422](https://api.guildwars2.com/v2/continents/1/floors/1/regions/37/maps/1422). All 31 challenge coordinates match API records exactly, with names matched through the [wiki interactive-map dataset](https://wiki.guildwars2.com/wiki/Widget:Interactive_map_data_builder/input.js).
- Outdoor terrain backgrounds use embedded ArenaNet tiles. The API repeats an outdoor rectangle for Arborstone; that hub uses the wiki’s interior coordinate crop with an explicitly labelled coordinate overview, rather than implying the outdoor terrain depicts the interior.
- [Tsuko Talonedge](https://wiki.guildwars2.com/wiki/Tsuko_Talonedge) requires [Base of Operations](https://wiki.guildwars2.com/wiki/Base_of_Operations). The generic challenge list’s “none” is insufficient. Entry via a friend does not grant this account mastery.
- [Lab District Terrace](https://wiki.guildwars2.com/wiki/Lab_District_Terrace) uses a powered [Jade Tech Teleporter](https://wiki.guildwars2.com/wiki/Jade_Tech_Teleporter) in the written approach. The jade bot and equipped power core are explicit prerequisites. Battery charges and temporary service interruptions are called out. The equipped core is tracked per character.
- [Garden Scaffolding](https://wiki.guildwars2.com/wiki/Garden_Scaffolding) supports basic Springer or a boosted-glider alternative. Gliding Booster and a powered jade bot are distinct from basic gliding. High Vault is never inferred from basic Springer.
- [Bloom of Seitung](https://wiki.guildwars2.com/wiki/Bloom_of_Seitung) supports gliding from the overlook or a Skimmer/Skiff approach. Ordinary swimming is not promised to reach the rock.
- [Submerged Cathedral](https://wiki.guildwars2.com/wiki/Submerged_Cathedral) requires locating a root-concealed cave and swimming through a narrow passage unmounted. Its travel rating reflects that navigation; no underwater mount is assumed.
- [Speaker Headquarters](https://wiki.guildwars2.com/wiki/Speaker_Headquarters) has a documented sequence of pillar/root/gate/ledge jumps. It is rated as precision travel and excluded by the conservative default jump filter.
- [Xunlai Jade Junkyard Overlook](https://wiki.guildwars2.com/wiki/Xunlai_Jade_Junkyard_Overlook) has incomplete basic-mount approach evidence, and the map list records unknown mastery requirements. It stays in the catalogue with an explicit unknown-prerequisite blocker, excluded from automatic plans.
- [Veteran Purist Necromancer](https://wiki.guildwars2.com/wiki/Veteran_Purist_Necromancer_(hero_challenge)) has story involvement. Its dialogue-risk flag excludes it from plans unless later-story dialogue is allowed. No plot summary is copied into the guide.
- Late-map challenges are communes, but nearby guards and map activity still affect combat/travel ratings. No successful map meta is prescribed as a prerequisite for the six HPs. Incomplete ascent directions remain visibly marked as partial evidence.

GuildJen’s [EoD hero point guides](https://guildjen.com/gw2-hero-points-guides/) provide per-map visual references and corroborate catalogue coverage. Text references were researched; embedded movement videos were not reviewed. Ratings are conservative editorial estimates, not recorded in-game runs or proven minimum requirements for every possible shortcut.

## Verification

Checked catalogue totals, unique IDs/labels, exact API coordinates and waypoint records, unchanged legacy challenge data, independent spoiler boundaries and cancellation, map access, region/mastery filters, unknown-prerequisite exclusion, old-save migration, notes/completions, reload persistence, backup restore and non-duplicating point credit. All 31 EoD selections were checked at 1440, 390 and 320 pixels for page overflow and clipped selected markers/waypoint labels. Embedded images loaded without JavaScript exceptions.
